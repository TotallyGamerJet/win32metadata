# win32metadata

win32metadata is a [Windows metadata parser](https://www.ecma-international.org/wp-content/uploads/ECMA-335_6th_edition_june_2012.pdf).

## Provenance

This is a continuation of `github.com/tdakkota/win32metadata`, which is no
longer available on GitHub. The first commit here is a verbatim copy of that
module at `v0.1.0`, retrieved from the Go module proxy; everything after it is
new work. The original is MIT licensed, Copyright (c) 2021 tdakkota, and
`LICENSE` is carried over unchanged.

The fork exists because the upstream repository was deleted while packages
still depended on it, leaving no way to publish fixes.

## Install

```
go get github.com/TotallyGamerJet/win32metadata@latest
```
